# Access Control Procedure

## Identity
Workforce and administrative access uses individually assigned accounts. Routine shared user accounts are prohibited.

## Authentication and privilege
Multi-factor authentication is required for privileged administrative access. Role assignment follows least privilege and requires an accountable owner.

## Lifecycle
Joiner, mover, and leaver events trigger access review. Confirmed departures require same-day disabling. Role changes require removal of access that is no longer needed.

## Review and logging
Privileged and production access is reviewed quarterly. Administrative access events are logged according to the production logging schedule.
