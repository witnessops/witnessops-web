Report or evidence?

Distinguish what an assistant says happened from the evidence you can inspect about a saved result. Then name the smallest useful next check.

PROPOSED title: Build Your First AI Operator. PROPOSED price hypothesis: €149 per learner for five founding places. PROPOSED syllabus: report or evidence; connect tools; finish the job; recover and repeat. Lessons 2–4 are outlines. This page does not take payment and does not open enrolment. Lesson text: prepared. A learner has not yet tried it. Suggested time: 20–30 minutes, as a planning estimate.

Lesson objective

You can separate a proposed action, an attempt, a reported result, an observed record, and a bounded verified match. You can also say what is still unknown.

I

A useful habit

“An assistant can describe a plan, quote a tool, or hand you a finished-looking answer. Inspect the evidence that belongs to the goal you actually set.”

For a task that should save a document, each link answers a different question:

Requested content → permitted action → tool response → retrieved saved content.

A matching retrieved record supports a bounded conclusion about that record at that time. It does not prove every property of the surrounding system.

Label set for this exercise
  • ProposedAn action is described as intended or suggested. No request has been shown.
  • AttemptedA request or job exists in the supplied artifact. Completion is a separate question.
  • ReportedAn assistant message says what happened. The message is not the saved record.
  • ObservedA retrieved record, response or destination state was actually read.
  • Verified for a bounded claimThe observed record matches the exact claim being checked, and the conclusion stays inside that match.
II

A worked example

Task: save a synthetic meeting summary in a test folder. No external service was called.

Available evidence · example

“The summary is saved.”

No tool request, response, document ID or retrieved document is available.

What this example supports Worked example
Supported conclusion
The assistant reported success. The saved result remains unknown.
Smallest useful next check
Locate the intended destination and retrieve the document through the supported read route. Compare its actual contents with the requested summary.
III

Your exercise

Cases A–D Invented teaching data

All names, IDs, timestamps and records below are invented. No external service was called. For each case, record what is supported, what remains unknown, and the smallest useful next check if one is needed. Use the label set above. This page does not mark your answers.

Case A — a confident message

The learner asks an agent to save a brief. The agent replies: “Done. Your brief is in the folder.” The transcript contains no tool event or saved-record reference.

Case B — a queued request

Synthetic response:

{
  "http_status": 202,
  "job_id": "SYNTHETIC-JOB-12",
  "state": "queued"
}

The assistant says the document has been saved. No later job state or retrieved document is available.

Case C — the matching saved result

The approved synthetic content is:

Title: Sample supplier brief
Finding: Two supplied sources disagree about the launch date.
Limit: No primary announcement was supplied.

The write response returns record ID SYNTHETIC-DOC-17, revision 1. A subsequent fresh read of that exact ID and revision returns the same title, finding and limit. The recorded destination matches the learner's approved test folder.

Case D — an uncertain response

A synthetic save request times out before a response arrives. The assistant says: “The save failed, so I will create it again.” The destination has not been read, and there is no saved-state evidence showing whether the first request committed.

Where to write: record the attempt in the workbook. Keep your original answer, then add reviewer feedback and your revision. This page has no save and no send.

IV

Before you move on

You are ready to move on when you can explain why Case C supports a stronger conclusion than A or B, and why Case D needs reconciliation before another create attempt.
