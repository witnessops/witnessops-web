II · Build agents

An agent is only as good as the job you gave it and the proof it has to leave.

Status: coming soon · lessons not written yet

Who it's for

People who build or configure AI agents: writing their instructions, choosing their tools, deciding when a job is finished.

The problem it solves

Agents report "done" when they stop, not when the work is complete. Without a clear job and a check that doesn't depend on the agent's own word, you only find out later.

What you'll be able to do

  • Write an agent job with a goal, limits and a definition of done.
  • Give the agent only the tools that job needs.
  • Make the agent leave a record you can check, not just a summary.
  • Handle a failed or half-finished run without starting from zero.

Lesson outline

  1. Write the job before the agent
  2. Tools for this job, and no more
  3. Done means someone else can check it
  4. Recover and repeat

Sovereign tools

Uses Sovereign Tasks to set agent jobs in the lessons.

What it isn't

Not a programming course. Not a framework comparison. Not a guide to giving agents more freedom.

Track II is being written. Until then, Track IV shows you how to check what an agent reports.
