IV · Verify results

A report is a sentence somebody wrote. Evidence is something you can open and check.

Status: pilot open · by invitation · Lessons 1 and 2 are pilot drafts

Who it's for

Anyone who has to decide whether an AI's report is true, whether you run the agent or just receive its results.

The problem it solves

Agents say "done, deployed and tested" in one breath. Some of that is true, some was never shown, and some a record contradicts. You need to tell which is which.

What you'll be able to do

  • Split a report into single claims.
  • Sort each claim: evidenced, only claimed, or contradicted.
  • Check a record is the same scope as the claim: same target, environment and time.
  • Name the artifact behind each verdict.
  • Write one honest limit: what the evidence does not prove.

Lessons (live pilot drafts)

  1. Report or evidence? Check an AI's report against what the record shows.
  2. Same record, wrong scope? A true record of a different environment, target or time is a gap, not a contradiction.

With a teacher: each lesson explains, shows a worked example, gives you an exercise on example data, then reads your attempt and helps you retry.

What it isn't

Coaching, not assessment. No grade, and no formal award in the pilot. It does not teach you to audit systems yourself.
