# Review workflow

The current paid review is [Agent Action Security Review](/reviews/agent-action-security-review) at €2,500 excluding VAT. It examines one consequential agent or automation action: what triggers it, which identity acts, what permissions it has, how approval works, and what execution evidence is available. Delivery timing agreed in the signed statement of work.

## 1. Send a non-secret fit check

Describe the one action you want reviewed, the systems involved, and your decision deadline in the [request form](/review/request?offerId=agent-action-security-review). Do not send files, logs, screenshots, customer evidence, credentials, private keys, API keys, session tokens, recovery codes or other secrets. An enquiry and mailbox confirmation establish contact only; neither books work nor authorises a review.

## 2. Agree scope and authority

Before inspection starts, agree the action boundary, approving authority, available sources, exclusions, evidence handling, recipients, fee and delivery timing in a signed statement of work. Required inputs, payment and operator capacity must also be confirmed. Only approved, non-secret source material may be shared after authority, scope and secure handling are agreed. A new action or wider workflow needs its own scope decision.

## 3. Reconstruct the agreed action

WitnessOps reads, inspects, reconstructs and reports against the agreed sources. The review maps the trigger, executing identity, effective permissions, approvals and available execution evidence. Findings identify their source; unavailable or inconclusive material remains an explicit unknown. If the agreed boundary no longer holds, work stops until the scope is resolved.

## 4. Receive the report and readout

The handover includes an action map, findings linked to sources, prioritised recommendations, documented unknowns, a written report and a readout. Your team decides whether and how to address the findings. Remediation and retesting are separate work, not part of this review.

The operating mode is read, inspect, reconstruct and report. The review does not execute the action, install a platform, change production or credentials, exploit a system, perform destructive testing, monitor continuously or certify that an agent is safe. It does not promise a full device inventory, cryptographic receipt or offline verifier as a standard deliverable. It is not a penetration test.

## Historical External Attack Surface Review

External Attack Surface Review is no longer available for new engagements. Issued agreements retain their original terms, including any agreed retest. Its public-facing-system checks and conditional receipt-profile package are historical terms; they do not describe or expand the Agent Action Security Review.

The legacy-named `public_exposure_review` profile remains a separate receipt-only compatibility path. Public [receipt checks](/docs/how-it-works/verification) remain `indeterminate` when the underlying authority, workflow, artifact bytes, evidence and production trust have not been independently checked. That path does not add a receipt or verifier to the current review's standard deliverables.

For the full request sequence, read the [Buyer path](/docs/getting-started/proof-run-buyer-path). To enquire about the current review, use the [non-secret fit check](/review/request?offerId=agent-action-security-review).
