## Operating rule

- **Catalog card** = buyer situation + handover package.
- **Scripts / KEV / SBOM tooling** = methods inside a package when scoped — never a product pitch.
- **Sample** = labelled synthetic. Never “your environment” or “we already tested you.”
- **Secrets:** fit check is non-secret only. See `PUBLIC_NO_SECRETS_NOTE` / email signature rules in [`../EMAIL-SIGNATURE-RESEND.md`](../EMAIL-SIGNATURE-RESEND.md).
