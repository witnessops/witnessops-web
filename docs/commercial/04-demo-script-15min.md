# 15-minute flagship demo script

**Audience:** founder, security buyer, or technical operator.  
**Goal:** show package shape + boundaries + next step (fit check).  
**Not a goal:** show every script, pilot, or operator platform.

---

## Time box

| Min | Step | URL |
| --- | ---: | --- |
| 0–2 | Situation framing | (talk only) |
| 2–4 | Catalog = situations not tools | https://witnessops.com/catalog |
| 4–8 | Primary sample (One Server **or** CSR) | sample URL below |
| 8–11 | Optional second sample | Launch **or** AI agent |
| 11–13 | Verify / limits | https://witnessops.com/verify |
| 13–15 | Fit check + commercial | https://witnessops.com/review/request |

---

## Opening (0–2)

Say:

> WitnessOps sells **bounded review packages** for one clear situation — not a portal of infinite tools. You pick the situation; we agree authority, scope, price, and handling; then we deliver something another person can inspect.

Ask:

1. What decision is blocked right now?  
2. One host, one questionnaire, or something else?

Route:

| They say | Demo primary |
| --- | --- |
| Questionnaire / vendor security | CSR |
| One Linux host / posture | One Server |
| Before/after launch | Launch sample (secondary) |
| “Show me all tools” | Redirect to methods strip + one sample |

---

## Catalog (2–4)

Open: https://witnessops.com/catalog  

Say:

> Six public situations. Cards are buyer problems. Operator scripts sit under the package when scoped — we do not sell a card per binary.

Point at **methods strip** if they ask about tooling:

> Infinite capabilities stay as methods. Catalog stays short on purpose.

---

## Primary A — One Server (4–8)

1. Service: https://witnessops.com/catalog/offsec-local-audit  
2. Sample: https://witnessops.com/review/sample-cases/local-server-security-review  
3. Open 1–2 package files (receipt / findings / walkthrough).  
4. Optional: download `.proofpack` and say “ZIP-compatible bytes for offline verify.”

**Must say:**

- One authorised host, read-only  
- Not a pentest  
- `valid` ≠ host is secure  
- €950 standard after fit check; collection only after authority  

**Must not say:**

- “We will scan your whole fleet”  
- “You’re safe after this”  
- “KEV / SBOM product”

## Primary B — CSR (4–8 alternative)

1. Service: https://witnessops.com/customer-security-review

**Must say:**

- One questionnaire, one product  
- They own final answers and send  
- No compliance certificate, no inventing evidence  
- From €1,600 after fit check

## Verify (11–13)

Open: https://witnessops.com/verify  

Say:

> Public verify is receipt-scoped for supported types. Suite packages also use offline product verifiers. We never invent a green check that the package does not name.

If no live receipt demo, stay on sample walkthrough text — do not fake a result.

---

## Close (13–15)

Open: https://witnessops.com/review/request  

Say:

> Next step is a non-secret fit check. No credentials, no keys, no evidence dump. If fit is clear, we send a scope agreement, then work.

Confirm:

1. Product (CSR / One Server / later)  
2. Decision owner  
3. Deadline  
4. Who sends the fit check today  

---

## Objection handling (30 seconds each)

| Objection | Response |
| --- | --- |
| “Can you just run your scripts?” | Scripts are methods inside a scoped package, not the product. |
| “Do you certify us?” | No. We package supportable answers or observations with limits. |
| “Is the sample our result?” | No — labelled synthetic for shape only. |
| “Multi-host?” | Pilot / multi-host is a different boundary; start with one host or one questionnaire. |
| “Price?” | Public lines on the service page; firm quote after fit check. |
