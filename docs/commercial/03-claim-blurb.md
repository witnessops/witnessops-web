# Claim blurbs (paste into scope + package + email)

Short blocks only. Prefer these exact limits over improvised wording.

---

## CSR Sprint

```text
This engagement produces a response package for one questionnaire and one product
scope: proposed answers, evidence references, qualifications, open items, and a
cover note for the customer’s approval.

The customer owns final answers, approvals, and submission. WitnessOps does not
certify compliance, invent evidence, or guarantee that a customer, auditor, or
procurement team will accept the package. Formal certifications remain necessary
where the reviewer requires them.
```

**One-liner:**  
`Proposed answers for one questionnaire — you own submission; not a compliance certificate.`

---

## One Server Security Check (`OFFSEC-LOCAL-AUDIT`)

```text
This engagement produces a bounded, read-only picture of one authorised Linux
host: posture, findings, report, and (where agreed) a signed proof package with
an offline inspection path.

It is not a penetration test, exploitation exercise, or compliance certification.
A valid verifier result (when a named path exists) confirms the checks named for
that package — not that the host is secure, uncompromised, or correctly
administered. Secrets and credentials are never requested in the fit check;
collection is only after authority and exclusions are agreed.
```

**One-liner:**  
`One authorised host, read-only package — not a pentest and not a security guarantee.`

## Shared package footer (any P0 delivery)

```text
Labelled samples on witnessops.com are synthetic and for orientation only.
They are not live customer evidence for your environment.

Start with a non-secret fit check. Do not send passwords, private keys, API keys,
recovery codes, session tokens, or other secrets until handling is agreed.
```

---

## Phrases to avoid (public + email)

| Avoid | Prefer |
| --- | --- |
| “You’re secure / compliant / audit-ready” | “Named checks completed under this scope” |
| “We verified your production” | “We packaged admitted, scoped observations” |
| “Guaranteed customer acceptance” | “Package for your approval and submission” |
| “Pentest of the host” | “Read-only One Server Security Check” |
| “KEV-clean / no known exploits” | Do not claim; methods only if in scope and limited |
| “Full environment audit” | “One host / one questionnaire / named boundary” |
