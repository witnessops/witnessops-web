# Admin Console reconciliation note

Status: `HISTORICAL_PUBLIC_STUB`

The operational Admin Console remains part of `witnessops-web`. Historical `witnessops-hq` work was used as a visual/interaction reference only; it was not adopted as a second production runtime, authentication system, API, or source of operational records.

The reconciliation did not intentionally change Admin authentication, lifecycle authority, proof/receipt semantics, Gmail/OIDC boundaries, DNS/Caddy authority, or public bilingual route behavior.

Detailed route mapping, validation counts, internal reconciliation evidence, and operator-specific history are maintained in restricted operator custody. The exact historical source remains reconstructable from Git history.
